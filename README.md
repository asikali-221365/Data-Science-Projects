## 📌 Project Overview

This project analyzes service demand patterns using Yelp business and review data.

The application provides interactive analysis of:

- 📍 Spatial Hotspots
- 📈 Demand Forecasting
- 😊 Customer Sentiment
- 🔍 Aspect-Based Sentiment Analysis
- 📊 Business Activity Trends

## 🛠️ Technologies

- Python
- Pandas
- Plotly
- Folium
- Streamlit
- DBSCAN
- Machine Learning
- Sentiment Analysis
